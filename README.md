# S2 Vocabulary · Click to Hear

Interactive reading page for S2 students.

Students can:
- tap a **word** to hear the pronunciation
- tap **Play sentence** to hear the example sentence
- switch UK / US accent
- slow the audio down
- search in English or Chinese
- filter by units A-E

## Student link

After GitHub Pages is turned on:

https://yunloong2000.github.io/s2-vocab-click-to-hear/

## Turn on GitHub Pages

1. Open the repository on GitHub
2. Settings → Pages
3. Source: Deploy from a branch
4. Branch: `main` / folder: `/ (root)`
5. Save

## Put it on a school website

Upload `index.html` to any web folder.
Best options: GitHub Pages, Netlify Drop, Cloudflare Pages, or the school server.

The page is one file. No login and no install.
